# The Hack House — Website starter

A warm, modern and child-friendly landing page concept for The Hack House. Includes a gently animated branded hero, scroll reveal animations, responsive navigation, program cards, brand-colour styling and the supplied logo.

The separate admission enquiry page is available at `/admission`. It includes browser-side required-field validation and a preview confirmation; submissions are not sent or stored because no admissions backend is configured.

## Run locally

1. Install Node.js (18+ recommended).
2. Open this folder in VS Code.
3. Open the terminal in this folder and run:

   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Before presenting to the client

Replace the illustrative content with confirmed information: exact programs, age groups, address, phone/email, schedule, registration process, policies and real activity photographs. Connect the admission enquiry form to an approved backend before collecting or processing real applications. The contact section currently links to the Instagram profile supplied in the brief. The decorative experience illustration is intentionally a placeholder until approved photography is available.

## Stack

- React + Vite
